為什麼需要設計原則？

一句話：生成式 AI 的「模糊性」是特性而非 Bug。好的設計原則幫你在不確定性中找到方向，打造以人為本的 Agent 系統。

對工程師來說，生成式 AI 的非確定性常讓人不知從何下手。微軟提出了一套以人為本的 UX 設計原則，不是死板的架構規範，而是團隊定義和打造 Agent 體驗的起點。

一個好的 Agent 應該做到：

  • 擴展人類能力——腦力激盪、問題解決、自動化
  • 填補知識缺口——快速掌握新領域、翻譯、摘要
  • 促進協作——以我們習慣的方式與他人合作
  • 讓我們變得更好——生活教練、情緒調節、建立韌性

三大 Agentic 設計原則

設計原則分為三個維度：空間（Space）、時間（Time）、核心（Core）。

一、Agent 空間設計（Space）

Agent 運作的環境——實體世界與數位世界中的設計考量。

原則繁體中文說明
連結而非取代
(Connecting, not collapsing)		 Agent 的使命是串聯人、事件與可操作的知識，促進協作與連結。Agent 讓人們更靠近彼此，不是用來取代或貶低人的。
易於存取，偶爾隱形
(Easily accessible yet occasionally invisible)		 Agent 大部分時間在背景運作，只在相關且合適時才推播提醒。支援多模態輸入/輸出（聲音、語音、文字），能在前景與背景、主動與被動之間無縫切換。即使隱形運作，其背景路徑和與其他 Agent 的協作仍對使用者透明且可控。

二、Agent 時間設計（Time）

Agent 如何跨時間運作——過去、現在、未來。

時間軸原則繁體中文說明
過去 (Past) 回顧歷史，包含狀態與脈絡 不只記錄事件，而是分析更豐富的歷史資料來提供更相關的結果。主動從過去事件中建立連結，反思記憶來應對當前情境。
現在 (Now) 引導勝於通知
(Nudging more than notifying)		 不只發送靜態通知。Agent 能簡化流程或動態生成提示，在對的時機引導使用者注意力。根據環境脈絡、社會文化變化、使用者意圖來傳遞資訊。互動可以漸進式地複雜化，長期賦能使用者。
未來 (Future) 適應與進化
(Adapting and evolving)		 適應各種裝置、平台和模態。適應使用者行為和無障礙需求，可自由客製化。透過持續的使用者互動不斷進化。

三、Agent 核心設計（Core）

Agent 設計中最關鍵的元素。

原則繁體中文說明
擁抱不確定性，但建立信任
(Embrace uncertainty but establish trust)		 某種程度的 Agent 不確定性是預期中的——這是 Agent 設計的關鍵元素。信任和透明度是 Agent 設計的基礎層。人類始終掌控 Agent 何時開/關，且 Agent 狀態隨時清晰可見。

落實設計原則的三大指南

1. 透明度（Transparency）

  • 告知使用者有 AI 參與
  • 說明 AI 如何運作（包含過往行為）
  • 提供回饋和修改系統的管道

2. 可控性（Control）

  • 讓使用者自訂偏好、個人化設定
  • 掌控系統及其屬性（包含「遺忘」的能力——刪除資料）

3. 一致性（Consistency）

  • 跨裝置、跨端點的一致多模態體驗
  • 使用熟悉的 UI/UX 元素（例如麥克風圖示代表語音）
  • 降低認知負擔：簡潔回應、視覺輔助、「了解更多」連結

實戰演練：用這些原則設計旅遊 Agent

假設你要設計一個旅遊 Agent，以下是套用設計原則的方式：

指南實際做法
透明度 讓使用者知道這是 AI 驅動的 Agent。提供基本使用說明（歡迎訊息、範例提示詞）。在產品頁面清楚標示。顯示使用者過往的提問記錄。明確提供回饋方式（讚/倒讚、回饋按鈕）。清楚說明使用限制和主題範圍。
可控性 讓使用者能修改 System Prompt 來自訂 Agent 行為。選擇 Agent 的回應詳細程度、寫作風格、以及不該觸及的話題。允許檢視和刪除相關檔案、資料、提示詞和過往對話。
一致性 使用標準且可辨識的圖示：分享提示詞、上傳檔案/照片、標記人員。使用迴紋針圖示代表檔案上傳，圖片圖示代表圖形上傳。

本課重點回顧

  1. 三大設計維度：空間（連結、可及性）、時間（過去回顧/現在引導/未來進化）、核心（信任+不確定性）
  2. 三大實作指南：透明度、可控性、一致性——這是所有 Agent 系統的基礎
  3. 不確定性是特性：不要試圖消除它，而是用透明度和信任來管理它
  4. 以人為本：Agent 擴展人的能力，不是取代人；人始終握有最終控制權
  5. 設計原則是起點：不是死板的架構規範，而是幫助團隊思考和討論的框架
