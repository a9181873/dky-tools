§6.2 脊迴歸與 Lasso：用懲罰項馴服過配

📖 ISLP §6.2 📄 pp. 245–260 ⭐⭐ ⏱️ 約 35 分鐘
regularization ridge lasso shrinkage variable-selection

📚 理論核心

📖 課本文獻引用：
James, Witten, Hastie & Tibshirani (2021). ISLP §6.2. Springer.
💡 核心概念（生活化比喻）：
想像你在挑選食材做菜。子集選擇法（§6.1）像是「只留高麗菜和番茄，其他全丟掉」，激進但容易浪費邊角料。Ridge 和 Lasso 則是「所有食材都留著，但有些只加一小撮」——它們在最小平方法中加了一個罰金（λ × 係數平方或絕對值），強迫每個變數的權重「向 0 收縮」，讓模型在偏差與變異之間找到甜蜜點。Ridge 像溫和的收縮（所有人一起縮），Lasso 像有選擇的收縮（不重要的人直接歸零出局）。

📐 數學定義

\[\hat{\beta}^{R}_{\lambda} = \arg\min_{\beta} \left\{ \sum_{i=1}^{n}(y_i - \beta_0 - \sum_{j=1}^{p}\beta_j x_{ij})^2 + \lambda \sum_{j=1}^{p} \beta_j^2 \right\}\]

Ridge 目標函數：懲罰項為係數平方和

\[\hat{\beta}^{L}_{\lambda} = \arg\min_{\beta} \left\{ \sum_{i=1}^{n}(y_i - \beta_0 - \sum_{j=1}^{p}\beta_j x_{ij})^2 + \lambda \sum_{j=1}^{p} |\beta_j| \right\}\]

Lasso 目標函數：懲罰項為係數絕對值和

🐍 實作程式碼

💻 Ridge 與 Lasso 正規化路徑圖 — 觀察 λ 變化時各係數如何收縮

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.linear_model import Ridge, Lasso
from sklearn.preprocessing import StandardScaler
from sklearn.model_selection import train_test_split

# 載入 Credit 資料集（來自 ISLP 套件）
from ISLP import load_data
Credit = load_data('Credit')
X = pd.get_dummies(Credit.drop('Balance', axis=1), drop_first=True)
y = Credit['Balance']

# 標準化（正規化前必須，否則懲罰項不公平）
scaler = StandardScaler()
X_scaled = scaler.fit_transform(X)
X_scaled = pd.DataFrame(X_scaled, columns=X.columns)

# 令 λ 對數均勻分佈
alphas = np.logspace(-2, 5, 100)

# Ridge 係數路徑
ridge_coefs = []
for a in alphas:
    ridge = Ridge(alpha=a)
    ridge.fit(X_scaled, y)
    ridge_coefs.append(ridge.coef_)

# Lasso 係數路徑
lasso_coefs = []
for a in alphas:
    lasso = Lasso(alpha=a, max_iter=10000)
    lasso.fit(X_scaled, y)
    lasso_coefs.append(lasso.coef_)

# 繪圖
fig, axes = plt.subplots(1, 2, figsize=(14, 5))
for i, (coefs, title) in enumerate(zip([ridge_coefs, lasso_coefs],
                                        ['Ridge (L2)', 'Lasso (L1)'])):
    ax = axes[i]
    ax.plot(alphas, coefs)
    ax.set_xscale('log')
    ax.set_xlabel('λ (log scale)')
    ax.set_ylabel('Coefficient')
    ax.set_title(title)
    ax.axhline(0, color='black', linewidth=0.5, linestyle='--')
    if i == 1:
        ax.legend(X.columns, fontsize=7, loc='upper right')
plt.tight_layout()
plt.savefig('ridge_lasso_path.png', dpi=100)
plt.show()
print('Ridge: 係數向 0 收縮但永遠不歸零')
print('Lasso: 不重要變數的係數會精確歸零（變數選擇）')

📤 預期輸出：兩張並排圖：左圖 Ridge 所有線平滑趨近 0；右圖 Lasso 線一條一條碰到 0 後消失

💻 交叉驗證選 λ — 用 10-fold CV 找最佳懲罰強度

from sklearn.linear_model import RidgeCV, LassoCV
from sklearn.model_selection import cross_val_score

# RidgeCV：內建 LOOCV 或 K-fold
ridge_cv = RidgeCV(alphas=np.logspace(-2, 5, 100), store_cv_values=True)
ridge_cv.fit(X_scaled, y)
print(f'Ridge 最佳 λ: {ridge_cv.alpha_:.2f}')
print(f'Ridge 最佳 CV MSE: {-ridge_cv.cv_values_.mean(axis=0).min():.2f}')

# LassoCV：用 10-fold CV（ISLP 偏好，比 LOOCV 穩定）
lasso_cv = LassoCV(alphas=np.logspace(-3, 2, 100), cv=10, max_iter=100000, random_state=1)
lasso_cv.fit(X_scaled, y)
print(f'\nLasso 最佳 λ: {lasso_cv.alpha_:.4f}')
print(f'Lasso 最佳 CV MSE: {-lasso_cv.mse_path_.mean(axis=1).min():.2f}')

# Lasso 選出的非零變數
coef = pd.Series(lasso_cv.coef_, index=X.columns)
nonzero = coef[coef != 0]
print(f'\nLasso 選出 {len(nonzero)}/{len(coef)} 個變數：')
print(nonzero.sort_values(ascending=False))

📤 預期輸出：Ridge 最佳 λ（較大）、Lasso 最佳 λ（較小且伴隨變數選擇）

🎯 應用場景

📊 行銷迴歸模型（高維度顧客屬性）

當顧客屬性多達數百項時，Lasso 可以自動挑出真正影響購買金額的 10-20 個變數，產出可解釋的簡約模型。

  • Ridge 適合所有變數都有微弱訊號的場景（如金融因子模型）
  • Lasso 適合大部分變數是雜訊的場景（如基因資料、文字特徵）

🏠 房價預測的彈性網

實際操作中常混合 Ridge + Lasso 成 Elastic Net（這門課不講，scikit-learn 有 ElasticNet），取兩者之長。但 ISLP §6.2 先讓你搞懂兩者的基本行為差異。

  • 先跑 Lasso 看哪些變數被留下來
  • 再用 Ridge 對留下的變數做最終預測（有時比純 Lasso 準）

⚖️ 優缺點

優點

  • ✅ 計算簡單（封閉解或凸優化）
  • ✅ Ridge 處理共線性極佳
  • ✅ Lasso 自動變數選擇，模型精簡
  • ✅ 交叉驗證選 λ 非常成熟

缺點

  • ⚠️ Ridge 不解釋變數重要性（全部保留）
  • ⚠️ Lasso 在 p>n 時最多選 n 個變數
  • ⚠️ λ 的選擇對結果影響巨大
  • ⚠️ 標準化是強制前置步驟，容易漏掉

🧠 自我內化

這對 Hermes 架構的啟發：Ridge/Lasso 的「懲罰項」概念與 agent memory 極其相似——不是所有經驗都該等權重記住。Lasso 式記憶管理（選擇性保留重要經驗、讓雜訊歸零）比 Ridge 式（全都記但打折）更適合 long-running agent。這呼應了 arXiv:2606.04536 TMEM 論文的參數化記憶思路。
