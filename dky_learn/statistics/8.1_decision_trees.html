🌳 決策樹：用問題來做預測

想像你在玩一個「20 個問題」的遊戲——透過一連串「是／否」問題縮小範圍，最終猜出答案。決策樹正是用同樣的邏輯來做預測：它把預測空間反覆切成小方塊，每切一刀就是一個問題（例如「年資 < 4.5 年？」），最終落在同一區塊的資料就給出相同的預測值。

核心概念：決策樹是一種將預測空間分層切割（stratification）的方法——把複雜的非線性關係，用一系列簡單的「若...則...」規則來逼近。它既可以處理迴歸（預測連續值），也可以處理分類（預測類別）。
James, Witten, Hastie, Tibshirani (2023) An Introduction to Statistical Learning, §8.1, pp.331–342. Springer.

📐 8.1.1 回歸樹（Regression Trees）

直觀理解：棒球薪資預測

課本以 Hitters 資料集為例：用 Years（大聯盟年資）和 Hits（去年安打數）來預測球員薪資。一棵簡單的回歸樹長這樣： 

            Years < 4.5
           /          \
     $165,174      Hits < 117.5
                   /           \
             $402,834        $845,346
圖 8.1 簡化版：Hitters 回歸樹。三個葉節點對應三種球員群體。

這棵樹把球員分成三個區域：

  • R₁：年資 < 4.5 年 → 預測薪資 $165,174
  • R₂：年資 ≥ 4.5 且安打 < 117.5 → 預測薪資 $402,834
  • R₃：年資 ≥ 4.5 且安打 ≥ 117.5 → 預測薪資 $845,346
直覺解讀：年資是最重要的因素；資深球員中，安打數才開始有顯著影響。這比線性迴歸的「每多一年加 $X、每多一安加 $Y」更容易向非技術人員解釋。

遞迴二元分割（Recursive Binary Splitting）

建立回歸樹的目標是：把預測空間切成 J 個不重疊的矩形區域 R₁, R₂, …, Rⱼ，使得每個區域內的觀測值盡可能相似。數學上就是最小化 RSS（殘差平方和）：

\[ \sum_{j=1}^{J} \sum_{i \in R_j} (y_i - \hat{y}_{R_j})^2 \]
公式 8.1：回歸樹的 RSS 目標函數

其中 \(\hat{y}_{R_j}\) 是第 j 個區域內所有訓練觀測值的 平均值。

但問題來了：要考慮所有可能的切割方式，計算量太大。因此採用遞迴二元分割——一個貪婪（greedy）策略：

貪婪策略（Greedy）：每一步只考慮當前最佳的一刀，不回頭考慮「這刀雖然現在不好，但後面會有好刀」的情況。就像下圍棋只看一步——雖然不是全局最優，但計算上可行。

對於每個預測變數 Xⱼ 和每個可能的切割點 s，定義兩個半平面：

\[ R_1(j, s) = \{X \mid X_j < s\}, \quad R_2(j, s) = \{X \mid X_j \geq s\} \]
公式 8.2：遞迴分割的兩個半平面

然後選擇使兩區域 RSS 之和最小的 (j, s)：

\[ \sum_{i: x_i \in R_1(j,s)} (y_i - \hat{y}_{R_1})^2 \;+\; \sum_{i: x_i \in R_2(j,s)} (y_i - \hat{y}_{R_2})^2 \]
公式 8.3：尋找最佳切割點

重複此過程：每次選擇一個現有區域，一刀切下去，直到滿足停止條件（如每個區域少於 5 筆資料）。

🌿 樹的修剪（Tree Pruning）

如果讓樹一直長下去，它會完美記憶訓練資料——也就是過度擬合。解法是：先讓樹長到最大（T₀），再用「成本複雜度修剪」（cost complexity pruning）把它修小。

\[ \sum_{m=1}^{|T|} \sum_{i: x_i \in R_m} (y_i - \hat{y}_{R_m})^2 \;+\; \alpha\,|T| \]
公式 8.4：成本複雜度修剪準則

這裡 |T| 是終端節點數，α 是調節參數：

  • α = 0 → 不修剪，T = T₀（最大樹）
  • α → ∞ → 修剪到只剩根節點
  • α 用交叉驗證來選擇最優值
與 Lasso 的類比：α 的角色就像 Lasso 迴歸中的 λ——都是透過懲罰複雜度來控制 bias-variance trade-off。但 Lasso 懲罰的是係數大小，決策樹懲罰的是葉節點數量。
Algorithm 8.1（課本 p.337）：建立回歸樹的完整步驟 — (1) 遞迴二元分割長出大樹；(2) 成本複雜度修剪得出子樹序列；(3) K-fold CV 選 α；(4) 回傳最優子樹。

🏷️ 8.1.2 分類樹（Classification Trees）

分類樹的結構和回歸樹一樣，差別在於：

  • 預測值：不是平均值，而是區域內最常見的類別
  • 切割準則：不能用 RSS，改用衡量「節點純度」的指標

三種節點純度指標

指標公式特性
分類錯誤率 \(E = 1 - \max_k(\hat{p}_{mk})\) 直觀但對樹的生長不夠敏感；適合用於修剪後的評估
Gini 指數 \(G = \sum_{k=1}^{K} \hat{p}_{mk}(1 - \hat{p}_{mk})\) 衡量總變異；值越小節點越純。sklearn 預設使用
熵（Entropy） \(D = -\sum_{k=1}^{K} \hat{p}_{mk} \log \hat{p}_{mk}\) 資訊理論概念；數值上與 Gini 很接近
Gini vs Entropy：兩者在實務上幾乎總是選出相同的切割。Gini 略快（不用算 log），是 sklearn 的預設；Entropy 在資訊理論上更優雅。重點是兩個都比分類錯誤率更敏感——分類錯誤率太「遲鈍」，可能看不出某些有價值切割的訊號。

課本以 Heart 資料集為例（303 位胸痛病人，預測是否患有心臟病），交叉驗證選出一個六葉節點的分類樹。樹中的切割變數包括 Thal（鉈壓力測試）、Ca（鈣含量）、MaxHR（最大心率）等。

import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np
from sklearn.tree import DecisionTreeRegressor
from sklearn.model_selection import cross_val_score, train_test_split
from ISLP import load_data

# 載入 Hitters，使用全部數值特徵
hitters = load_data('Hitters')
hitters = hitters.dropna(subset=['Salary'])
hitters['logSalary'] = np.log(hitters['Salary'])

features = ['AtBat', 'Hits', 'HmRun', 'Runs', 'RBI',
            'Walks', 'Years', 'CAtBat', 'CHits', 'CHmRun',
            'CRuns', 'CRBI', 'CWalks', 'PutOuts', 'Assists', 'Errors']
X = hitters[features].values
y = hitters['logSalary'].values

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.5, random_state=1)

# 長出大樹
big_tree = DecisionTreeRegressor(random_state=42)
big_tree.fit(X_train, y_train)
print(f"大樹葉節點數: {big_tree.get_n_leaves()}")

# 取得 cost complexity pruning path
path = big_tree.cost_complexity_pruning_path(X_train, y_train)
ccp_alphas = path.ccp_alphas[:-1]

# 用 cross-validation 找最佳 alpha
cv_scores = []
for alpha in ccp_alphas:
    tree = DecisionTreeRegressor(ccp_alpha=alpha, random_state=42)
    scores = cross_val_score(tree, X_train, y_train, cv=5,
                             scoring='neg_mean_squared_error')
    cv_scores.append(-scores.mean())

best_alpha = ccp_alphas[np.argmin(cv_scores)]
print(f"最佳 alpha: {best_alpha:.6f}")

# 用最佳 alpha 訓練最終樹
final_tree = DecisionTreeRegressor(ccp_alpha=best_alpha, random_state=42)
final_tree.fit(X_train, y_train)
print(f"修剪後葉節點數: {final_tree.get_n_leaves()}")
test_mse = np.mean((y_test - final_tree.predict(X_test))**2)
print(f"Test MSE: {test_mse:.4f}")

# 繪圖
plt.figure(figsize=(10, 5))
plt.plot(ccp_alphas, cv_scores, 'b-o', markersize=4, label='CV MSE')
vline = plt.axvline(best_alpha, color='red', linestyle='--',
                     label=f'Best alpha={best_alpha:.4f}')
plt.xlabel('alpha (cost complexity parameter)')
plt.ylabel('Cross-validated MSE')
plt.title('Cost Complexity Pruning: CV Error vs alpha')
plt.legend()
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.savefig('/tmp/pruning_cv.png', dpi=100)
plt.show()

分類樹：Heart 心臟病預測

import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from sklearn.tree import DecisionTreeClassifier, plot_tree
from sklearn.model_selection import cross_val_score, GridSearchCV
from ISLP import load_data

# 載入 Heart 資料（從 statlearning.com 下載的 CSV）
heart = pd.read_csv(DATA_PATH + 'Heart.csv')

# 準備特徵和目標
X_df = pd.get_dummies(heart.drop('AHD', axis=1), drop_first=True)
X = X_df.values
y = (heart['AHD'] == 'Yes').astype(int).values

# 用 CV 選擇最佳葉節點數
param_grid = {'max_leaf_nodes': range(2, 21)}
grid = GridSearchCV(
    DecisionTreeClassifier(random_state=42),
    param_grid, cv=5, scoring='accuracy'
)
grid.fit(X, y)

print(f"最佳葉節點數: {grid.best_params_['max_leaf_nodes']}")
print(f"CV 準確率: {grid.best_score_:.3f}")
print(f"訓練準確率: {grid.score(X, y):.3f}")

# 可視化最佳分類樹
best_tree = DecisionTreeClassifier(
    max_leaf_nodes=grid.best_params_['max_leaf_nodes'],
    random_state=42
)
best_tree.fit(X, y)

plt.figure(figsize=(14, 7))
plot_tree(best_tree, feature_names=X_df.columns,
          class_names=['No HD', 'HD'], filled=True, rounded=True, fontsize=7)
plt.title(f'Heart 分類樹 (max_leaf_nodes={grid.best_params_["max_leaf_nodes"]})')
plt.tight_layout()
plt.savefig('/tmp/heart_classification_tree.png', dpi=100)
plt.show()

# 比較 Gini vs Entropy
for criterion in ['gini', 'entropy']:
    clf = DecisionTreeClassifier(criterion=criterion, random_state=42)
    scores = cross_val_score(clf, X, y, cv=5, scoring='accuracy')
    print(f"{criterion}: CV accuracy = {scores.mean():.3f} "
          f"(+/- {scores.std():.3f})")

💼 應用場景

🏥 醫療診斷輔助

決策樹是最受醫生歡迎的 ML 模型——因為它可以畫出來。一棵心臟病風險決策樹可以印在一張紙上，醫生按圖索驥：先看 thal 測試結果 → 再看最大心率 → 再看膽固醇...，最終得出風險評估。這種透明性在醫療領域至關重要。

💳 信用審核

銀行審核貸款時，決策樹可以提供明確的審核路徑：「收入 < 3 萬 → 負債比 > 40% → 拒絕」。比起黑箱深度學習模型，決策樹可以給客戶一個清楚的拒絕理由，符合金融監管對「可解釋性」的要求。

📊 客戶分群

行銷團隊用決策樹將客戶分群：「年消費 > 5000 且最近購買天數 < 30 → VIP 客戶」。行銷人員不需要懂統計，看樹狀圖就能理解客戶分類邏輯。

⚖️ 優缺點對照

✅ 優點

  • 高度可解釋——可以直接畫成樹狀圖展示
  • 不需要特徵標準化——樹的切割只關心相對順序
  • 自動處理非線性關係——不需手動加入多項式項
  • 天然處理混合型資料——連續和類別變數可以共存
  • 對離群值穩健——切割點基於排序，不受極端值影響

❌ 缺點

  • 預測準確度較低——單棵樹通常不如其他監督學習方法
  • 高變異性——資料的小變化可能導致完全不同的樹結構
  • 容易過度擬合——不加限制的樹可以完美記憶訓練資料
  • 貪婪策略非全局最優——每次只看一步，可能錯過更好的全域結構
  • 不擅長線性關係——用階梯狀逼近斜線，效率不如線性迴歸

🧠 自我內化：從決策樹看 AI 代理架構

對 Hermes 架構的啟發：決策樹的「遞迴分割 → 修剪 → 集成」三階段，正好映射到 AI 代理系統的設計挑戰：

🔹 遞迴分割 ≈ 任務分解：就像決策樹把預測空間切成小區域，複雜任務也需要被分解成可管理的小步驟。但「貪婪策略」的陷阱提醒我們：只看一步的任務分解（每次都做看似最優的子任務）未必得到全局最優解。

🔹 修剪 ≈ 簡化：一個有 500 個子步驟的任務計畫就像沒修剪的決策樹——看似完美覆蓋所有情況，實則過度擬合。Ponytail 紀律（YAGNI、最少檔案數）正是代理系統的 cost complexity pruning。

🔹 集成 ≈ 多代理協作：單棵決策樹準確度不高，但本章後續的 Bagging / Random Forest / Boosting（多棵樹投票）將準確度提升數倍。對應到代理系統：單一 agent 的判斷有限，多 agent 協作（delegate_task + critic）才是提升可靠度的關鍵。
