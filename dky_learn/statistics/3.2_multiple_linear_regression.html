從簡單迴歸到多元迴歸：為什麼需要多個預測變數？

在 §3.1 中，我們用「電視廣告預算」一個變數來預測銷售額，得到了不錯的結果。但現實世界遠比這複雜——銷售額可能同時受到電視、收音機、報紙等多個廣告管道的影響。如果我們分別對每個預測變數擬合一個簡單線性迴歸，會產生兩個嚴重問題：

⚠️ 分別擬合的陷阱：
1. 無法做單一預測——三個模型給出三個不同的預測值，該信哪一個？
2. 忽略變數間的相關性——如果各廣告預算之間彼此相關（例如：在收音機廣告花費高的市場，報紙廣告花費也偏高），則簡單迴歸係數將產生嚴重誤導。

解決方案是多元線性迴歸模型（Multiple Linear Regression）——將所有預測變數放入同一個模型，每個變數擁有自己的斜率係數。

\[ Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \epsilon \tag{3.19} \]
多元線性迴歸模型（\(p\) 個預測變數）

其中 \(\beta_j\) 代表在其他預測變數保持不變的情況下，\(X_j\) 每增加一單位對 \(Y\) 的平均影響。以廣告資料為例：

\[ \text{sales} = \beta_0 + \beta_1 \times \text{TV} + \beta_2 \times \text{radio} + \beta_3 \times \text{newspaper} + \epsilon \tag{3.20} \]
James, Witten, Hastie, Tibshirani (2023) An Introduction to Statistical Learning with Python, §3.2, pp. 81–90. 核心概念：多元線性迴歸將簡單線性迴歸推廣到多個預測變數的情境，每個係數 \(\beta_j\) 解釋為「其他變數固定時，\(X_j\) 對 \(Y\) 的平均邊際效果」。

3.2.1 估計迴歸係數：最小平方法的推廣

與簡單線性迴歸類似，我們使用最小平方法（Least Squares）來估計 \(\beta_0, \beta_1, \ldots, \beta_p\)——選擇能使殘差平方和（RSS）最小化的參數值：

\[ \text{RSS} = \sum_{i=1}^{n} (y_i - \hat{y}_i)^2 = \sum_{i=1}^{n} (y_i - \hat{\beta}_0 - \hat{\beta}_1 x_{i1} - \hat{\beta}_2 x_{i2} - \cdots - \hat{\beta}_p x_{ip})^2 \tag{3.22} \]

不同於簡單線性迴歸有封閉解（closed-form），多元迴歸的係數估計需要用矩陣代數來表示，形式較為複雜，但任何統計軟體都能輕鬆計算。在幾何上，當 \(p=2\) 時，最小平方解對應到三維空間中的一個平面（而非簡單迴歸的直線），該平面最小化了所有觀測點到平面的垂直距離平方和。

🦈 鯊魚攻擊 vs. 冰淇淋銷量：經典的混淆變數案例

ISLP 課本用一個幽默的例子說明這個現象：如果你對某海灘社區進行迴歸分析，會發現冰淇淋銷量與鯊魚攻擊次數呈正相關。難道要禁止冰淇淋來防止鯊魚攻擊？當然不是！真正的原因是高溫同時導致更多人前往海灘（→ 更多冰淇淋銷量）以及更多人下水（→ 更多鯊魚攻擊）。當你把「溫度」加入多元迴歸後，冰淇淋銷量就不再是顯著預測變數了。這就是混淆變數（confounding variable）的經典示範。

3.2.2 多元迴歸的四大核心問題

進行多元線性迴歸時，我們通常關心以下四個問題：

  1. 至少有一個預測變數對反應變數有預測力嗎？
  2. 所有預測變數都有幫助，還是只需要部分子集？
  3. 模型對資料的擬合程度如何？
  4. 給定一組預測變數值，該如何預測反應變數？預測有多準確？

問題一：反應變數與預測變數之間是否存在關係？

在簡單迴歸中，檢查 \(\beta_1 = 0\) 即可。在多元迴歸中，我們需要同時檢驗所有係數是否皆為零：

\[ H_0: \beta_1 = \beta_2 = \cdots = \beta_p = 0 \quad \text{vs.} \quad H_a: \text{至少有一個 } \beta_j \neq 0 \]

為此我們使用 F 統計量（F-statistic）：

\[ F = \frac{(\text{TSS} - \text{RSS}) / p}{\text{RSS} / (n - p - 1)} \tag{3.23} \]

其中 TSS（Total Sum of Squares）= \(\sum (y_i - \bar{y})^2\)。如果線性模型假設成立且 \(H_0\) 為真，則 F 統計量的期望值接近 1；若 \(H_a\) 為真，F 會顯著大於 1。

⚠️ 多重檢定的陷阱：為什麼需要 F 檢定而不只看個別 p 值？
假設有 p = 100 個預測變數，且 \(H_0\) 為真（沒有任何變數與 Y 有關）。在顯著水準 α = 0.05 下，平均會有約 5 個變數的 p 值 < 0.05，純屬隨機。如果只根據個別 p 值做判斷，極可能誤判存在關係。F 統計量自動校正了預測變數的數量，在 \(H_0\) 為真時，無論 p 多大，只有 5% 的機率給出 p < 0.05。

此外，F 檢定也可以檢驗特定子集的係數是否為零。假設我們想檢驗最後 q 個變數是否需要（即 \(H_0: \beta_{p-q+1} = \cdots = \beta_p = 0\)），可以擬合不包含這 q 個變數的簡化模型（其殘差平方和為 \(\text{RSS}_0\)），然後計算：

\[ F = \frac{(\text{RSS}_0 - \text{RSS}) / q}{\text{RSS} / (n - p - 1)} \tag{3.24} \]

問題二：哪些變數真正重要？——變數選擇

當 F 檢定顯示「至少有一個預測變數有用」後，下一步是找出哪些變數才是真正重要的。這就是變數選擇（Variable Selection）問題（將在第六章深入探討）。

窮舉法的困境：對於 p 個預測變數，可能的模型組合有 \(2^p\) 種。如果 p = 30，需要考慮超過 10 億 個模型——完全不可行。

三種經典的自動化變數選擇策略：

📈 向前選擇（Forward Selection）

  • 從虛無模型（僅有截距）開始
  • 每次加入一個能最大程度降低 RSS 的變數
  • 持續直到滿足停止條件
  • 計算量較小，適合 p 較大時使用

📉 向後選擇（Backward Selection）

  • 從完整模型（所有變數）開始
  • 每次移除 p 值最大（最不顯著）的變數
  • 持續直到剩餘變數的 p 值都低於閾值
  • ⚠️ 需要 n > p 才能擬合完整模型

🔄 混合選擇（Mixed Selection）

  • 結合向前和向後選擇的優點
  • 從空模型開始逐步加入變數
  • 每次加入新變數後，檢查是否可以移除不再顯著的舊變數
  • 實務中最常用的策略

模型品質的評估指標包括：Mallow's \(C_p\)、AIC（Akaike Information Criterion）、BIC（Bayesian Information Criterion）、以及調整後 \(R^2\)（Adjusted \(R^2\)）。這些指標在擬合度和模型複雜度之間取得平衡。

問題三：模型擬合度——RSE 與 R²

在多元迴歸中，我們同樣使用 RSE 和 \(R^2\) 來評估模型擬合度，但計算方式需要調整：

\[ \text{RSE} = \sqrt{\frac{\text{RSS}}{n - p - 1}} \quad ; \quad R^2 = 1 - \frac{\text{RSS}}{\text{TSS}} \]
RSE 使用 \(n-p-1\) 作為自由度，以懲罰模型的複雜度

由於 \(R^2\) 在加入更多變數時永遠不會下降（即使加入的是雜訊變數），單純用 \(R^2\) 來比較不同大小的模型會傾向選擇最複雜的模型。這就是為什麼在變數選擇中，我們偏好使用調整後 \(R^2\)、AIC、BIC 等懲罰模型複雜度的指標。

📊 圖形診斷：當數字不夠用時

圖 3.5（課本 p.89）展示了 TV 和 radio 對 sales 的三維擬合圖。雖然 \(R^2 = 0.897\) 看似不錯，但殘差呈現明顯的非線性模式：當廣告預算均勻分配在 TV 和 radio 之間時，模型傾向低估銷售額；當預算集中在單一媒體時，模型傾向高估。這暗示著 TV 和 radio 之間存在交互作用（interaction）——同時使用兩個媒體的效果大於單獨使用之和。這個問題將在 §3.3.2 中透過加入交互項來解決。

問題四：預測與不確定性

一旦擬合了多元迴歸模型，就可以用 (3.21) 來做預測：

\[ \hat{y} = \hat{\beta}_0 + \hat{\beta}_1 x_1 + \hat{\beta}_2 x_2 + \cdots + \hat{\beta}_p x_p \tag{3.21} \]

但預測伴隨著三種不確定性來源：

不確定性來源類型說明
1. 係數估計誤差 可縮減誤差 \(\hat{\beta}_j\) 只是 \(\beta_j\) 的估計值，最小平方平面 \(\hat{Y}\) 不等於真實母體迴歸平面 \(f(X)\)
2. 模型偏差 可縮減誤差 線性模型只是真實關係的近似，可能存在模型設定錯誤（model misspecification）
3. 隨機誤差 \(\epsilon\) 不可縮減誤差 即使完全知道真實的 \(f(X)\)，隨機擾動 \(\epsilon\) 仍使預測無法完美

📏 信賴區間（Confidence Interval）

  • 量化 \(f(X)\) 的估計不確定性
  • 回答：「平均銷售額的真實值落在哪裡？」
  • 例：TV=$100K, radio=$20K → 95% CI = [10,985, 11,528]
  • 只反映可縮減誤差

🔮 預測區間（Prediction Interval）

  • 量化 \(Y\) 的個別預測不確定性
  • 回答：「某個特定城市的銷售額會是多少？」
  • 例：TV=$100K, radio=$20K → 95% PI = [7,930, 14,580]
  • 同時反映可縮減 + 不可縮減誤差 → 永遠比 CI 寬

🏭 應用場景：工廠產能預測

一家製造業公司希望預測每日產量（units）。預測變數包括：生產線數量（lines）和工人數（workers）。使用多元線性迴歸可以得到：

units ≈ 1.2 + 3.4 × lines + 0.22 × workers

這表示：每增加一條生產線，在其他條件不變下，每日產量平均增加 3.4 單位。但這個模型假設 lines 和 workers 的效果是可加的（additive）——實際上，如果沒有工人，增加生產線也不會提高產量。這正是 §3.3.2 中將討論的交互作用問題。

💳 金融場景：信用卡餘額預測

銀行想預測客戶的信用卡餘額（balance）。使用收入（income）、信用額度（limit）、信用卡數量（cards）作為預測變數進行多元迴歸。透過 F 檢定確認至少有一個變數與 balance 相關後，再使用變數選擇技術找出最重要的預測因子。特別是當預測變數之間存在相關性時（如 income 和 limit 通常正相關），多元迴歸能夠分離出每個變數的獨立貢獻，這在信用風險評估中至關重要。

🏥 醫療場景：病患住院天數預測

醫院使用多元線性迴歸預測病患住院天數，預測變數包括年齡、共病症數量、入院時的生命徵象指標等。F 檢定用來確認整體模型是否有預測力，而變數選擇（如向後選擇）可以篩選出真正影響住院天數的關鍵因子，幫助醫院進行床位管理和資源配置。預測區間（而非信賴區間）更適合用於個別病患的預估，因為它包含了個體差異的不可縮減誤差。

✅ 多元線性迴歸的優點

  • 控制混淆：能分離各預測變數的獨立效果
  • 更準確的預測：利用多個資訊來源
  • 解釋力強：係數有清晰的「其他條件不變」解讀
  • 計算高效：即使 p 很大，最小平方也有解析解
  • 推論架構完整：F 檢定、t 檢定、信賴區間、預測區間

⚠️ 多元線性迴歸的限制

  • 線性假設：假設 Y 與 X 之間為線性關係
  • 可加性假設：假設各變數效果獨立（無交互作用）
  • 多重共線性：預測變數高度相關時係數估計不穩定
  • 高維度限制：當 p > n 時無法使用最小平方法
  • 離群值敏感：最小平方法對極端值非常敏感
在簡單迴歸中，你看到的是影子；在多元迴歸中，你看到的是形體本身。 — 改寫自 ISLP §3.2 的核心精神：控制其他變數，才能看清每個預測變數的真實效果
