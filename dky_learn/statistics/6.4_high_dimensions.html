6.4 高維度資料的考量：當特徵比觀測值還多時

📖 ISLP 6.4 📄 pp. 267-272 ⏱️ approx 25 min
regularization high-dimensional sparsity curse-of-dimensionality

📚 理論核心

📖 課本文獻引用：
James, Witten, Hastie, Tibshirani (2021). An Introduction to Statistical Learning, 6.4, pp. 267-272.
💡 核心概念（生活化比喻）：
高維度就像在一個巨大倉庫裡只放了三本書，卻要猜出所有書架的排列規則。傳統迴歸在 p < n 時如魚得水，但一旦 p > n（例如 5000 個基因、僅 100 位病人），最小平方法直接崩潰——因為有無限多組係數可以完美擬合資料。核心教訓：高維度下，你必須「賭稀疏性」（bet on sparsity），亦即相信只有少數變數真的重要。Ridge 和 Lasso 這類正則化方法不是選項，而是生存必需品。

📐 數學定義

\[ p > n \Rightarrow \text{OLS has no unique solution} \]

高維度最小平方法崩潰：變數多於觀測值時，X^T X 不可逆

\[ \text{MSE}_{\text{test}} = \text{Var}(\hat{f}) + \text{Bias}^2(\hat{f}) + \text{Var}(\epsilon) \]

高維度下變異數暴增，即使偏差為零，MSE 仍然很差

🐍 實作程式碼

💻 模擬 p=500, n=100 時 OLS vs Ridge vs Lasso 的測試誤差

import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

np.random.seed(42)
n, p = 100, 500  # p >> n: high-dimensional

# Sparse true model: only 5 features matter
beta_true = np.zeros(p)
beta_true[:5] = [3.0, -2.0, 1.5, 0, 0.8]

X = np.random.randn(n, p)
y = X @ beta_true + np.random.randn(n) * 0.5

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=30, random_state=1)

# OLS fails when p > n (singular matrix)
try:
    ols = LinearRegression().fit(X_train, y_train)
    mse_ols = mean_squared_error(y_test, ols.predict(X_test))
except:
    mse_ols = float('inf')

ridge = Ridge(alpha=1.0).fit(X_train, y_train)
lasso = Lasso(alpha=0.1, max_iter=5000).fit(X_train, y_train)

print(f"OLS  MSE (test): {'CRASH' if mse_ols==float('inf') else mse_ols:.3f}")
print(f"Ridge MSE (test): {mean_squared_error(y_test, ridge.predict(X_test)):.3f}")
print(f"Lasso MSE (test): {mean_squared_error(y_test, lasso.predict(X_test)):.3f}")
print(f"\nLasso selected {np.sum(lasso.coef_ != 0)} non-zero coefs (true model has 5)")

📤 預期輸出：OLS crashes; Ridge/Lasso produce reasonable MSE; Lasso selects few variables

📊 應用場景

Gene Expression Analysis

5000 genes x 200 patients. Goal: find genes associated with cancer prognosis.

  • Lasso auto-selects dozens of candidate genes
  • Ridge distributes weights among correlated gene groups

Marketing Mix Modeling

Hundreds of media channel variables, only a few quarters of weekly data.

  • Regularization forces model to keep only truly predictive channels
  • Avoids mistaking noise for media effects

📊 維度情境比較表

DimensionOLSRidgeLasso
p < n (low)OK unbiasedSmall bias, lower varCan do variable selection
p ~ n (medium)High varianceStableGood choice
p > n (high)CRASH (no unique solution)Must useBest (sparsity)
p >> n (ultra-high)Completely unusableUsable with cautionOK if truly sparse

⚖️ 優劣勢

✅ 優勢

  • ✅ Regularization is the only way in high dimensions
  • ✅ Lasso does both estimation + variable selection
  • ✅ Ridge is more stable under high collinearity

⚠️ 限制

  • ⚠️ Any model in high dimensions has limited interpretability
  • ⚠️ Cross-validation may be unstable when p >> n
  • ⚠️ Bet on sparsity may not hold for all problems

In high dimensions, you must bet on sparsity - believe that only a few predictors truly matter. This is not an option; it is a survival requirement.

— Adapted from Hastie, Tibshirani & Friedman

🧠 自我內化

This chapter's insight for Hermes: Hermes' skill system (skills/) is itself a form of 'regularization' - instead of stuffing all knowledge into the prompt, only load truly relevant skills. The core contradiction of high-dimensional problems (too many variables, too few observations) is isomorphic to the fundamental dilemma of agent prompt engineering (limited context, infinite information). Lasso bets on sparsity; Hermes bets on 'load only relevant skills'. This is not a coincidence - it's the same mathematical principle.
