6.4 高維度資料的考量：當特徵比觀測值還多時

📖 ISLP 6.4 📄 pp. 267-272 ⏱️ approx 25 min
regularization high-dimensional sparsity curse-of-dimensionality

📚 理論核心

📖 課本文獻引用：
James, Witten, Hastie, Tibshirani (2021). An Introduction to Statistical Learning, 6.4, pp. 267-272.
💡 核心概念（生活化比喻）：
高維度就像在一個巨大倉庫裡只放了三本書，卻要猜出所有書架的排列規則。傳統迴歸在 p < n 時如魚得水，但一旦 p > n（例如 5000 個基因、僅 100 位病人），最小平方法直接崩潰——因為有無限多組係數可以完美擬合資料。核心教訓：高維度下，你必須「賭稀疏性」（bet on sparsity），亦即相信只有少數變數真的重要。Ridge 和 Lasso 這類正則化方法不是選項，而是生存必需品。

📐 數學定義

\[ p > n \Rightarrow \text{OLS has no unique solution} \]

高維度最小平方法崩潰：變數多於觀測值時，X^T X 不可逆

\[ \text{MSE}_{\text{test}} = \text{Var}(\hat{f}) + \text{Bias}^2(\hat{f}) + \text{Var}(\epsilon) \]

高維度下變異數暴增，即使偏差為零，MSE 仍然很差

🐍 實作程式碼

💻 模擬 p=500, n=100 時 OLS vs Ridge vs Lasso 的測試誤差

import numpy as np
from sklearn.linear_model import LinearRegression, Ridge, Lasso
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error

np.random.seed(42)
n, p = 100, 500  # p >> n: high-dimensional

# Sparse true model: only 5 features matter
beta_true = np.zeros(p)
beta_true[:5] = [3.0, -2.0, 1.5, 0, 0.8]

X = np.random.randn(n, p)
y = X @ beta_true + np.random.randn(n) * 0.5

X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=30, random_state=1)

# OLS fails when p > n (singular matrix)
try:
    ols = LinearRegression().fit(X_train, y_train)
    mse_ols = mean_squared_error(y_test, ols.predict(X_test))
except:
    mse_ols = float('inf')

ridge = Ridge(alpha=1.0).fit(X_train, y_train)
lasso = Lasso(alpha=0.1, max_iter=5000).fit(X_train, y_train)

print(f"OLS  MSE (test): {'CRASH' if mse_ols==float('inf') else mse_ols:.3f}")
print(f"Ridge MSE (test): {mean_squared_error(y_test, ridge.predict(X_test)):.3f}")
print(f"Lasso MSE (test): {mean_squared_error(y_test, lasso.predict(X_test)):.3f}")
print(f"\nLasso selected {np.sum(lasso.coef_ != 0)} non-zero coefs (true model has 5)")

📤 預期輸出：OLS crashes; Ridge/Lasso produce reasonable MSE; Lasso selects few variables

📊 應用場景

基因表現分析

5000 個基因 × 200 位病患。目標：找出與癌症預後相關的關鍵基因。

  • Lasso 自動篩選出數十個候選基因
  • Ridge 將權重分散到相關基因群組中

行銷組合建模

數百個媒體管道變數，僅有少數幾季的週資料可供建模。

  • 正則化強制模型只保留真正具預測力的管道
  • 避免將雜訊誤判為媒體效果

📊 維度情境比較表

維度情境OLSRidgeLasso
p < n（低維度）無偏估計微小偏差、降低變異可做變數篩選
p ~ n（中維度）高變異穩定理想選擇
p > n（高維度）崩潰（無唯一解）必須使用最佳（稀疏性）
p >> n（超高維度）完全不可用謹慎可用若真稀疏則可行

⚖️ 優劣勢

✅ 優勢

  • ✅ 正則化是高維度情境的唯一解方
  • ✅ Lasso 同時做到估計與變數篩選
  • ✅ Ridge 在高度共線性下更穩定

⚠️ 限制

  • ⚠️ 高維度下任何模型的可解釋性都有限
  • ⚠️ p >> n 時交叉驗證可能不穩定
  • ⚠️ 稀疏性假設不適用於所有問題

在高維度中，你必須賭稀疏性——相信只有少數預測變數真的重要。這不是選項，而是生存要件。

— 改編自 Hastie, Tibshirani & Friedman
