深度一：資料分析 Plugin - 最危險賽道

它做什麼

讓業務分析師用自然語言問問題，Codex 自動查詢 Snowflake/Databricks、執行 SQL、解釋結果、生成儀表板。

過去流程：業務問「Q2 營收為啥降 8%」 > 分析師開 Snowflake 寫 SQL > 匯出到 Tableau > 建圖表 > 寫解釋 > 寄出。跨 3 工具、半天到一天。

現在：業務直接問 Codex > 3 分鐘拿到附圖表報告。分析師從 SQL 寫手變成審查者。

誰會被影響

Tableau / Looker：威脅最大。Codex 吃掉的是「撈資料 + 做圖表 + 寫解釋」中間層。Tableau Creator $70/月 vs Codex $30/月。

Snowflake / Databricks：相對安全。Codex 需要它們儲存和查詢資料。使用量反而可能增加，但查詢模式從批次變成即興自然語言查詢。

Hex / Deepnote：中度威脅。非嚴謹場景可被取代；嚴謹科學場景有「程式碼可審查、可複現」防禦優勢。

我的判斷

不是消滅 BI 工具，是把使用者界面從「拖拉建圖表」變成「對話問問題」。不是同一個賽道競爭，是在重新定義賽道。Tableau 繼續優化拖拉就打錯戰場了。

最危險：BI 視覺化（Tableau / Looker / Mode）。最安全：雲端 DW（Snowflake / Databricks / BigQuery）。

深度二：銷售 Plugin - CRM 生態震央

它做什麼

連接 Salesforce、HubSpot、Slack、Outreach、Clay、Rox、Actively 七個工具。核心價值：自動化銷售人員 60-70% 準備工作時間。

  • 會議準備：拉客戶歷史 + Slack 對話 + Outreach 郵件往來 > 結構化備忘錄
  • CRM 更新：跨 Salesforce + HubSpot 同步更新，不需手動打字
  • 跟進排程：分析 pipeline + 最近互動 + 競品 > 優先排序 + 建議行動

誰會被影響

Salesforce：短期安全，長期受壓。護城河是 10 年客戶資料不是 UI。但如果 80% CRM 操作透過 Codex，企業會問：「還需要每人 $150/月的 Enterprise 授權嗎？」

Outreach / Salesloft：高度威脅。郵件序列 + 追蹤回覆可被 Codex 完全吸收。

HubSpot：中度威脅。中小企業對價格敏感，$30 vs $800 Professional。

我的判斷

最大顛覆點不是「取代 CRM」——CRM 從「目的地」變成「後端」。業務不再登入 Salesforce 更新欄位，而是跟 Codex 對話。CRM 的 user engagement 和 DAU 會大幅下降。

最危險：銷售互動平台（Outreach / Salesloft）。最安全：CRM 核心（Salesforce）——但授權費有長期壓力。

其他四個 Plugin

創意製作

Figma/Canva 是創作工具非工作流工具。Codex 可生初稿，品牌調性無可取代。低創造性任務（快速社群貼文）可能讓 Canva 入門用戶流失。

產品設計

更像是 Figma 延伸非替代。產品設計是高度人際過程，AI 只能輔助難主導。

權益投資 + 投資銀行

高價值低人數金融市場。解放初級分析師資料整理時間。合規要求（人簽名、數據溯源）短期難滿足。Bloomberg Terminal $24,000 年費。

落地應用

對企業

  1. 立即評估 Plugin 與現有 SaaS stack 重疊度。用 Tableau + Snowflake 的團隊可考慮重談 Tableau 授權。
  2. 不要急著砍 SaaS。信任不是一夕建立。先輔助，確認品質穩定再討論減授權。
  3. 關注互動層戰爭。Codex 終局不是取代任何 SaaS — 而是成為 SaaS 之上的統一互動層。誰擁有自然語言輸入就擁有重新分配價值的權力。

對個人

  • 做「搬資料 + 做圖表 + 寫說明」的 — AI 已做到 80%，該升級到判斷層（對不對、為什麼對、怎麼行動）。
  • 做 Sales Ops 的 — 建立策略設計能力（非手動操作能力）是未來護城河。

限制與風險

幻覺風險：SQL 寫錯（join 錯表、日期範圍錯），整個分析都是錯的。目前無自動稽核機制。
權限災難：跨 CRM + Slack + Outreach 讀寫 — 一個 prompt 可洩漏跨系統資料。Plugin 權限設定目前還很粗。
供應商鎖定：操作層 + 資料存取層全綁在 OpenAI。漲價或改 API，整個工作流受影響。
成熟度不均：六個 Plugin 深度明顯不同。資料分析和銷售有真正雙向讀寫；創意和設計偏單向生成；金融依賴昂貴外部數據授權。
