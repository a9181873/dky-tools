H-Mem：結合時間語義樹與知識圖的混合記憶演化機制

arXiv: 2605.15701 · 2026-05-30
Jiawei Yu, Yixiang Fang · 港中深 + Xilin Liu, Yuchi Ma · 華為雲
短期記憶逐步演化為長期摘要，保留實體關係圖，在多個代理記憶 QA 基準達 SOTA。

一句話

港中深與華為雲聯合提出 H-Mem，將時間語義樹與知識圖結合，使短期記憶逐步演化為結構化長期摘要，保留實體關係，達 SOTA。

關鍵數據

項目數據
作者港中深 + 華為雲
核心結構時間語義樹 + 知識圖
記憶演化短期→中期摘要→長期結構化知識
實驗結果多個 agent memory QA 基準達 SOTA

機制拆解

  • 時間語義樹：依時間軸組織對話，相似主題聚合為節點
  • 知識圖層：抽取實體及關係，建構圖結構
  • 演化觸發：節點超閾值或時間窗口關閉時壓縮為摘要

落地應用

  • Hermes MEMORY + fact_store 雙軌接近 H-Mem 的兩層設計
  • 可加入時間衰減機制讓舊記憶自動降權
  • MEMORY 壓縮流程可參考時間語義樹的聚合邏輯
