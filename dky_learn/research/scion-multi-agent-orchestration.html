Scion：多 Agent 容器編排平台

Google Cloud Platform · GitHub 開源專案 · Apache License 2.0 · 原始專案
讓多個深度 Agent 在獨立容器、工作區、Git worktree 與憑證環境中平行協作。

摘要

Scion 是多 Agent 編排與執行層，負責啟動、隔離、管理及觀測執行中的 Agent。每個 Agent 可使用自己的容器、工作區與選配 Git worktree，降低同時修改同一專案時的干擾。

  • 預設支援 Claude Code 與 Gemini CLI，也可擴充其他 Harness。
  • 支援 Docker、Podman、Apple Container 與 Kubernetes。
  • 提供啟動、附加、傳訊息、日誌、停止、恢復與刪除等生命週期管理。
  • 支援 Agent 模板、tmux、遠端執行與 OpenTelemetry 觀測。

應用

  • 把軟體開發拆成多個平行角色，例如實作、測試、安全審查與文件整理。
  • 在隔離容器中執行互不信任或需要不同依賴的 Agent。
  • 跨本機、遠端 VM 或 Kubernetes 執行大量長時間任務。
  • 以 Markdown 定義角色、工具與協作規則，測試不同多 Agent 工作模式。
  • 搭配 GitHub Issues、Linear、Beads 等任務系統，以及外部記憶系統組成完整 Agent 工廠。

建議

目前不需要導入。只有在多 Agent 工作量增加到需要獨立容器、Git worktree、長時間背景執行或跨主機調度時，才值得建立小型 PoC。

PoC 應先限制在非正式專案，確認容器權限、Secrets 隔離、網路出口、映像檔來源、日誌與清理機制。

限制與注意事項

Scion 著重執行隔離與編排，不負責完整的記憶、任務管理、模型路由或對外 Gateway。導入時仍需自行設計權限、Secrets、網路出口、資料持久化、成本控管與容器映像檔供應鏈。

專案仍在快速演進，Local、Hub 與 Kubernetes API 可能變動；另外，雖由 Google Cloud Platform 維護，但官方聲明不是 Google 正式支援產品。
