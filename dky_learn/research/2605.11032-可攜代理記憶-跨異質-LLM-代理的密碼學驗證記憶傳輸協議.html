可攜代理記憶：跨異質 LLM 代理的密碼學驗證記憶傳輸協議

arXiv: 2605.11032 · 2026-05-30
Santhosh Kumar Ravindran · Microsoft Corporation
透過密碼學簽章讓不同 LLM 代理之間安全遷移操作上下文，解決供應商鎖定與知識遺失。

一句話

Microsoft Research 提出可攜代理記憶協議 (PAM)，透過密碼學簽章驗證，讓不同模型、平台的 AI 代理安全轉移操作記憶，打破供應商鎖定。

關鍵數據

項目數據
作者Santhosh Kumar Ravindran, Microsoft
核心技術密碼學簽章 + 標準化記憶格式
應用場景跨平台代理遷移、記憶備份、多代理協作

機制拆解

  • 標準化格式：統一的記憶序列化協議，與底層 LLM 無關
  • 密碼學簽章：每筆記憶攜帶來源代理的私鑰簽章，接收方可驗證完整性
  • 信任鏈：記憶可跨多代理傳遞，每站附加簽章形成信任鏈

落地應用

  • Hermes 跨 profile 的記憶隔離可參考此協議統一遷移
  • 子 agent 產出結果可附加簽章確保內容未被篡改
  • 從 DeepSeek 換模型時記憶可攜是長期需求
