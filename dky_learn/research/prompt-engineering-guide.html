🔧 核心技術拆解

技術機制對 DKY 體系的直接應用
ReAct 推理（Thought）→ 行動（Action）→ 觀察（Observation）循環 Hermes agent 底層邏輯；任何需工具呼叫的 AI Agent 都基於此模式
RAG 檢索外部知識庫 → 增強 LLM 生成品質 Paperless-ngx 文件問答、dkyc.info 跨論文查詢、Notion 知識庫檢索
Prompt Chaining 將複雜任務拆成多階段，輸出餵入下一階段 n8n 內容策展管線：搜集→篩選→分析→發布，每階段獨立 prompt
Chain-of-Thought 強制模型輸出中間推理步驟 複雜保單缺口分析、研究論文摘要，提升推理準確度
APE 自動搜尋最優 prompt 指令，取代人工試錯 n8n 工作流、子 agent 指令自動優化，不需手動調 prompt
Outlines 約束 LLM 輸出為嚴格的 JSON/Pydantic schema 保險公式提取、API 回應結構化、多模型審查報告格式統一

🛠 值得關注的工具推薦

工具類別推薦理由
Ollama本地 LLM 執行DKY 環境已部署，Guide 列為 CLI 首選

ChainlitChat UI 框架快速為任何 LLM 應用加上對話介面，適合原型展示
Outlines結構化生成強制 JSON 輸出，適合 API 回應格式、保險公式提取

💡 落地應用建議

1. 技術選型第一站：任何 LLM 相關技術選型，先翻 Guide 對應章節看推薦什麼，取代 Google 亂搜。80+ 工具按類別整理，省去大量評估時間。
2. n8n Prompt 模板庫：每個 n8n LLM 節點撰寫 prompt 時，直接引用 Guide 的 CoT/ReAct/Few-Shot 範本，確保 prompt 設計有學理依據而非靠感覺。
3. 論文素材來源：Guide 每項技術都附原始論文（Yao 2022 ReAct、Wei 2022 CoT、Zhou 2022 APE 等），可作為 dkyc.info 研究筆記的持續素材來源，論文引用鏈完整可追溯。
4. 優先評估三工具：Ollama（已部署）、Outlines（結構化輸出剛需）、Dify（n8n 互補）。這三個是對 DKY 體系立即有價值的工具。
⚠ 注意：Dify 偏向視覺化 LLM 應用平台，與 n8n 有功能重疊。建議先在獨立環境試用，確認互補關係後再決定是否整合。PromptBench 測試需消耗 API 呼叫次數，使用免費模型測試時注意 rate limit。
